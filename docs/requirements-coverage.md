# 项目开发与管理平台后端需求覆盖矩阵

更新时间：2026-07-08

## 覆盖结论

按当前约定“只做后端、不做前端”统计，Word 需求中涉及的后端主流程已经基本覆盖。当前代码已具备项目、任务、需求、Bug、日报、项目汇报、文件、通知、首页、系统权限、操作日志、Excel 导出、Swagger 中文文档和生产配置模板。

未纳入后端代码完成口径的内容：前端页面与交互、真实生产服务器部署、真实 MySQL/Redis/OSS 账号和域名配置、正式数据初始化口径。这些属于联调/部署阶段，不是后端业务代码缺口。

## 后续联调清单

| 项目 | 说明 |
| --- | --- |
| 前端页面 | 当前后端已提供接口和 Swagger 字段说明，前端页面不在本仓库实现范围。 |
| 部署参数 | 需要在服务器配置真实 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`、`REDIS_*`、`JWT_SECRET`。 |
| OSS 切换 | 代码已有阿里云 OSS 存储实现，生产切换时设置 `PROJECTFLOW_STORAGE_TYPE=aliyun-oss` 和 OSS 环境变量。 |
| 初始账号 | Flyway 已有种子数据脚本，正式上线前需要确认账号、角色和权限码是否符合公司实际组织。 |
| 数据验收 | 建议用 Swagger 按模块做一轮接口验收，再进入前后端联调。 |
